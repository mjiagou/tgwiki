# Telegram 隐藏功能与高手技巧大全：30+ 个让你效率翻倍的实用秘技

用了好几年 Telegram，还是只会在群里发文字？其实 Telegram 远比你想象的强大。本文整理了 30+ 个最实用的隐藏功能和高手技巧，从消息管理到文件传输，从搜索到快捷键，帮你从普通用户进阶为 Telegram 高手。

---

## 一、消息技巧

### 1. 定时发送消息

在聊天中长按发送按钮（移动端）或右键发送按钮（桌面端），会弹出**定时发送**选项：

- **自定义时间**：精确到分钟，设定未来某个时间自动发送
- **当对方在线时发送**：检测到对方上线才发出（仅限私聊）
- **定时消息管理**：在聊天中发送 `/settimer` 或在消息气泡上长按可查看/取消未发出的定时消息

::: tip 应用场景
- 跨时区工作：给海外同事设定对方工作时间发送
- 生日祝福：零点准时发送
- 频道运营：提前排期内容自动发布
:::

### 2. 静默发送（无通知）

长按发送按钮 → 选择 **静默发送（Send Without Sound）**，消息会正常送达，但对方**不会收到通知声音和震动**。

::: tip 应用场景
- 深夜给同事发工作消息不打扰
- 给群组发非紧急信息避免打扰所有人
- 发送大量消息时避免连续通知轰炸
:::

### 3. 消息编辑与编辑历史

- **编辑已发送消息**：长按/右键消息 → 编辑（移动端双击消息也可编辑）
- **查看编辑历史**：在已编辑的消息上长按/右键 → 「编辑历史」可查看所有修改记录
- **编辑时限**：频道和群组消息可永久编辑（需管理员开启权限），私聊消息可编辑 48 小时

::: warning 注意
编辑消息不会触发新通知，对方可能看不到你的修改。重要修改建议新发一条消息。
:::

### 4. 消息自毁（自动删除）

- **私聊自毁**：在加密对话中可设置消息 1 秒~1 周后自动删除
- **普通聊天自动删除**：聊天设置 → 开启「自动删除」→ 选择 1 天 / 1 周 / 1 个月
- **单条消息自毁**：长按消息 → 转发到「加密对话」中设置自毁时间

### 5. 引用回复的高级用法

- **引用部分文字**：选中消息中的部分文字 → 右键/长按 → 回复（只引用选中的部分）
- **引用图片/文件**：直接回复带媒体的消息，引用中会显示缩略图
- **取消引用**：点击引用预览上方的「×」可取消引用关系
- **多消息引用**：桌面端可选中多条消息 → 右键 → 转发/回复

### 6. 消息反应（Reaction）

- **快速反应**：双击消息（移动端）或在消息上右键（桌面端）选择 emoji 反应
- **自定义反应**：Premium 用户可使用自定义表情包中的表情作为反应
- **反应查看**：点击消息下方的反应数字可查看谁给了什么反应
- **取消反应**：再次点击同一个 emoji 即可取消

## 二、文件与云存储

### 7. 收藏夹 = 免费无限云盘

Telegram 的「收藏夹（Saved Messages）」是一个**无限的云端存储空间**：

| 特性 | 普通用户 | Premium |
|:---|:---|:---|
| 单文件上限 | 2 GB | 4 GB |
| 存储总量 | 无限 | 无限 |
| 多端同步 | ✅ | ✅ |
| 文件格式 | 任意 | 任意 |

**使用技巧：**
- 发送文件到收藏夹时添加文字备注，方便搜索
- 用 `#标签` 组织文件，如 `#工作 #报告`
- 文件可转发到任意聊天，不消耗二次上传时间
- 支持创建文件夹分类管理收藏内容

::: tip 快速打开收藏夹
- 桌面端：`Ctrl+0`（Windows）/ `Cmd+0`（Mac）
- 移动端：搜索框输入自己的用户名 → 收藏夹
:::

### 8. 发送 uncompressed 原图

默认发送图片会被压缩。发送**无损原图**的方法：

- **移动端**：选择图片后点击右上角的「📋」图标 → 选择「发送为文件」
- **桌面端**：拖拽图片到聊天窗口时按住 `Shift` 键 → 变为发送文件
- **批量原图**：选择多张图片 → 发送为文件 → 自动打包为 zip

### 9. 文件流式播放

Telegram 支持视频/音频的**流式播放**：

- 大视频发送后，接收方可以**边下载边播放**，不需要等下载完成
- 音频文件支持后台播放和锁屏控制
- 支持播放速度调节（0.5x ~ 2x）
- 支持画中画模式（移动端）

### 10. 群组/频道文件聚合

在群组或频道中，点击聊天名称 → **媒体/文件/链接** 标签页，可以按类型浏览所有共享内容：

- **媒体**：所有图片和视频
- **文件**：所有文档和压缩包
- **链接**：所有分享过的链接
- **语音**：所有语音消息

### 11. 用 Bot 上传大文件

通过 Bot API 可以上传最大 50 MB 的文件（Bot 限制），通过 MTProto 用户 API 可以上传最大 2 GB 文件：

```python
# python-telegram-bot 上传文件示例
async def upload_file(update, context):
    with open("large_file.zip", "rb") as f:
        await context.bot.send_document(chat_id=update.effective_chat.id, document=f)
```

## 三、搜索与发现

### 12. 全局搜索语法

Telegram 搜索支持以下过滤维度：

| 操作 | 方法 |
|:---|:---|
| 搜索特定聊天中的消息 | 搜索 → 输入关键词 → 选择「在此聊天中搜索」 |
| 搜索所有聊天 | 搜索 → 输入关键词 → 选择「全部对话」 |
| 按日期搜索 | 输入 `dd.mm.yyyy` 或 `dd.mm.yyyy-dd.mm.yyyy` |
| 搜索媒体类型 | 搜索 → 点击搜索栏右侧的图标选择类型 |
| 搜索 hashtag | 直接输入 `#标签名` |
| 搜索用户名 | 在搜索框输入 `@用户名` |

### 13. 中文搜索优化

Telegram 的中文搜索以**词组**为单位，标点符号作为分词符：

```
原始消息：辜鸿铭说过：真正的自由，并不意味着可以随心所欲

可搜索词组：真正的自由 / 并不意味着可以随心所欲
```

**优化方法：**
- 在消息中用 `#` 或空格手动分词
- 频道主在内容中添加 `#标签`
- 桌面端可导出 JSON 后用外部工具搜索

### 14. 搜索表情包和贴纸

在贴纸面板点击搜索图标，输入关键词即可搜索**全网公开贴纸包**。支持中文搜索。

### 15. 发现附近群组

虽然「附近的人」功能已被移除，但你仍然可以在搜索中输入相关主题关键词，找到公开群组和频道。

## 四、聊天管理

### 16. 聊天文件夹高级过滤

聊天文件夹不仅限于按类型分类，还可以设置**排除规则**：

- **包含**：选择特定的聊天、机器人、群组类型
- **排除**：排除特定聊天（如不想在工作文件夹中看到娱乐群）
- **推荐**：把工作群放入一个文件夹，排除所有频道，打造纯净工作区

::: tip 共享文件夹
你可以把一个文件夹打包成链接分享给好友，对方点击即可一次性加入文件夹中的所有群组和频道。详见 [聊天分组指南](./folder.md)。
:::

### 17. 归档的隐藏技巧

- **归档不会丢失消息**：归档只是隐藏到单独列表
- **归档不会取消通知**：被归档的聊天仍然可以收到通知（除非单独静音）
- **隐藏归档栏**：在移动端可以把归档栏隐藏，下拉才显示
- **批量归档**：长按一个聊天 → 选择多个 → 批量归档

### 18. 置顶消息管理

| 操作 | 方法 |
|:---|:---|
| 置顶单条消息 | 长按/右键消息 → 置顶 |
| 置顶多条消息 | 普通用户最多 5 条，Premium 最多 |
| 通知对方 | 置顶时可选择是否通知对方 |
| 群组置顶管理 | 群组设置 → 置顶消息 → 管理所有置顶 |
| 频道置顶 | 频道设置 → 置顶消息 |

### 19. 慢速模式

群组可以设置慢速模式，限制成员发言频率：

- 可选间隔：10秒 / 30秒 / 1分钟 / 5分钟 / 15分钟 / 1小时
- 管理员不受限制
- 有效防止刷屏和机器人轰炸

### 20. 以频道身份发言

频道管理员可以在群组中**以频道身份发言**，消息显示为频道名而非个人：

- 群组设置 → 管理员 → 添加频道管理员
- 发言时在输入框左侧切换身份

## 五、隐私与安全技巧

### 21. 阅后即焚（加密对话）

**加密对话（Secret Chat）** 提供端到端加密：

- 消息不经过服务器存储，只存在于双方设备
- 支持消息自毁（1 秒 ~ 1 周）
- 截图通知（部分客户端）
- 无法转发、无法保存到收藏夹
- 每个设备独立加密对话（不同设备需重新发起）

::: warning 限制
加密对话不支持群组，仅限一对一私聊。且对方必须在线才能建立。
:::

### 22. 在线状态隐藏

- **隐藏「最后上线时间」**：设置 → 隐私 → 最后上线 → 选择「没有人」
- **隐藏「正在输入」**：第三方客户端（如 Nagram）支持隐藏输入状态
- **隐藏「在线」绿点**：隐藏最后上线时间后，绿点也会同时对他人隐藏
- **例外设置**：可以设置白名单/黑名单，让特定人可见或不可见

### 23. 手机号隐藏

设置 → 隐私 → 手机号 → 选择「没有人」：

- 别人通过手机号无法找到你的 Telegram
- 防止手机号泄露后被陌生人添加
- 建议同时设置用户名，方便通过用户名添加

### 24. 转发隐私

设置 → 隐私 → 转发消息 → 选择「没有人」：

- 别人转发你的消息时不会显示你的名字
- 转发会变为「匿名来源」
- 有效防止信息追溯和骚扰

### 25. 会话管理

设置 → 设备 → 可以查看所有已登录设备：

- **远程退出**：点击任意设备可远程退出
- **自动清理旧会话**：设置中选择「6 个月后自动退出不活跃设备」
- **会话通知**：新设备登录时会收到通知

- 在手机上写了半句话，切到电脑上继续写
- 草稿保存在云端，不会丢失
- 支持带格式（粗体、链接等）的草稿

### 29. 频道评论区的隐藏功能

- **点赞/踩**：频道评论可点赞或踩

- **评论区管理**：频道管理员可删除/置顶评论

- 无需注册，直接编写文章
- 支持富文本、图片、视频嵌入
- 文章链接可在 Telegram 中预览
- 适合写长文公告、教程

## 七、高级技巧

### 31. 用 Telegram 传文件到电脑

无需数据线，用 Telegram 当「无线 U 盘」：

1. 手机打开收藏夹 → 发送文件
2. 电脑打开 Telegram → 收藏夹 → 下载文件
3. 速度比蓝牙快几十倍，不限文件类型

### 32. 批量删除消息

- **移动端**：长按一条消息 → 选择多条 → 删除
- **桌面端**：选中消息（Shift+点击）→ 右键 → 删除
- **删除范围**：可选「删除我和对方的消息」或「只删除我的」
- **Bot 批量删除**：使用群管 Bot（如 Rose）的 `/del` 命令

### 33. 创建投票和测验

- **普通投票**：支持单选/多选/匿名
- **测验模式**：设置正确答案，答对显示 ✅ 答错显示 ❌
- **实时结果**：投票后可查看实时统计
- **关闭投票**：创建者可随时停止投票

### 34. 视频通话变屏幕共享

在视频通话中点击「屏幕共享」按钮：
- 共享整个屏幕或单个窗口
- 支持同时共享音频（电脑端）
- 适合远程演示和协作

### 35. 频道数据分析

频道主可以在频道设置 → 统计中查看：
- **增长曲线**：订阅者增长/流失趋势
- **受众分布**：粉丝语言、时段活跃度
- **内容表现**：每条帖子的浏览量、转发量、反应数
- **来源分析**：订阅者从哪里来（搜索/链接/转发）

### 36. 限制保存内容

频道/群组管理员可以开启「限制保存内容」：
- 禁止成员转发消息
- 禁止成员保存图片/视频
- 禁止截屏（移动端）
- 有效防止付费内容被搬运

详见 [防搬运与版权保护指南](./copyright-protection.md)。

## 八、彩蛋与趣味

### 37. 生日蛋糕动画

在聊天中发送 `🎂` 或 `🎉` 时，如果当天是你的 Telegram 注册纪念日或生日（设置了生日），整个聊天界面会出现**满屏飘落的动画效果**。

### 38. 表情雨

发送特定 emoji 组合会触发全屏动画：

- `🎉` / `🎊` → 彩纸飘落
- `❤️` / `💗` → 爱心飞出
- `🔥` → 火焰特效
- `👍` → 点赞动画
- `♨️` → 蒸汽效果

### 39. 消息字数统计

在桌面端选中一段文字，底部状态栏会显示**字符数和单词数**，适合写长文时参考。

### 40. 频道表情包定制

达到 Boost 2 级的频道可以设置**自定义频道表情包**：
- 频道消息的反应表情可替换为自定义贴纸包
- 增强频道品牌识别度
- 详见 [频道助推指南](./boost.md)
